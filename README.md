## 📌 Sobre o Repositório

Este repositório foi criado com o objetivo de **aprimorar meus conhecimentos em Lógica de Programação e desenvolver meu raciocínio lógico**, por meio da resolução de exercícios e da implementação de pequenos projetos em Java.

Aqui compartilho minha evolução nos estudos, colocando em prática conceitos fundamentais da programação e buscando desenvolver soluções cada vez mais eficientes e organizadas.

## 🎯 Objetivos

- Aprimorar minha lógica de programação.
- Desenvolver o raciocínio lógico e a capacidade de resolver problemas.
- Praticar e fortalecer meus conhecimentos em Java.
- Compreender melhor algoritmos e estruturas de controle.
- Aprender a escrever códigos mais limpos e organizados.
- Acompanhar minha evolução como desenvolvedor.

## 📚 Conteúdos Praticados

- Variáveis e tipos de dados.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `else` e `switch`).
- Estruturas de repetição (`for`, `while` e `do-while`).
- Arrays e manipulação de dados.
- Métodos e funções.
- Algoritmos e resolução de problemas.

## 🚀 Projetos Desenvolvidos

 * Calculadora | Operações matemáticas básicas.
 * Jogo de Adivinhação | Prática de condicionais, repetição e lógica.
 * Lista de Tarefas | Gerenciamento simples de tarefas.
 * Sistema de Notas | Cálculo de médias e verificação de resultados.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Editor:** Visual Studio Code
- **Versionamento:** Git e GitHub

## 📈 Evolução

Este repositório será atualizado conforme avanço nos estudos, adicionando novos exercícios, desafios e projetos que contribuam para meu desenvolvimento na programação.

**O objetivo não é apenas fazer o código funcionar, mas compreender a lógica por trás de cada solução.**
